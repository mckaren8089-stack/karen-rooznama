# Snapshot 0.2 — دوطرفه‌سازی تبدیل تاریخ و مدیریت یادداشت‌ها

## قابلیت‌های ثبت‌شده
- تبدیل **شمسی به میلادی** و **میلادی به شمسی** در یک ابزار، با نمایش نتیجه و بازکردن روز در تقویم.
- اضافه‌شدن زبانه **یادداشت‌ها**: دیدن همه یادداشت‌ها به‌ترتیب تاریخ، بازکردن تاریخ مربوط، و حذف هر یادداشت.
- تعداد یادداشت‌ها در زبانه و روی **هر روز تقویم** نمایش داده می‌شود. روی موبایل لمس روز، پنل جزئیات را به دید می‌آورد.
- دکمه‌های **دریافت پشتیبان JSON** و **بازیابی از JSON** در زبانه یادداشت‌ها؛ بازیابی به‌صورت ادغام بدون ثبت دوباره متن یکسان است.
- تغییر ماه، روز انتخاب‌شده را به ماه جدید منتقل می‌کند (با محدودکردن روز به انتهای آن ماه).
- بهبود اندازه نمایش تاریخ و کارت‌های سال در صفحه موبایل.
- نسخه کش آفلاین PWA به 0.2 تغییر کرد و فایل notes.mjs هم ذخیره می‌شود.

## ذخیره‌سازی و حریم خصوصی
- منبع اصلی یادداشت‌ها **localStorage مرورگر همان گوشی** با کلید \`karen-rooznama-notes-v1\` است.
- هیچ یادداشت شخصی در مخزن GitHub، GitHub Pages یا فایل JSON روی سرور نوشته نمی‌شود.
- JSON فقط **درخواستی و محلی** ساخته/دریافت می‌شود. برای پشتیبان‌گیری واقعی، کاربر باید فایل را در جایی امن نگهداری کند.
- حذف داده‌های مرورگر ممکن است یادداشت‌ها را پاک کند؛ نصب PWA و Chrome بسته به محیط می‌توانند داده مجزایی داشته باشند.
- اکنون همگام‌سازی بین دستگاه‌ها و اعلان یادآور وجود ندارد.
- داده مناسبت‌ها هنوز نمونه‌ای و ناقص هستند، نه نسخه تأییدشده دانشگاه تهران؛ مناسبت‌های مذهبی در رابط نمایش داده نمی‌شوند.

## کنترل کیفیت
- اجرای Node check و آزمون‌های تبدیل تاریخ و قالب JSON در GitHub Actions انجام می‌شود.
- آزمایش روی دستگاه اندروید و عملکرد دریافت/بازیابی فایل باید توسط کاربر تأیید شود.
- مرور مستقیم صفحه منتشرشده از محیط دستیار ممکن نبود؛ کاربر صفحه 0.1 را روی Chrome اندروید باز کرده و اسکرین‌شات‌های واقعی ارائه داده است.

## تصمیم‌های باز
- ورود تقویم رسمی دانشگاه تهران و فیلتر مناسبت‌های مذهبی در زمان ورود داده.
- انتخاب و نهایی‌کردن مجوز نرم‌افزار برای **Karen Rooznama** و به‌طور مستقل **Karen Fuse**.
- خرید دامنه اختیاری در آینده. فعلاً سایت از GitHub Pages رایگان استفاده می‌کند.
- معماری نهایی React/TypeScript و امکانات یادآور/همگام‌سازی در نسخه‌های بعدی بررسی شود.
