# تصمیم‌های معتبر روزنمای کارن

این سند تصمیم‌های فعلی پروژه را ثبت می‌کند؛ README فقط برای معرفی عمومی برنامه است.

## محصول
- نام: روزنمای کارن / Karen Rooznama؛ تقویم ایرانی مینیمال و دفتر برنامه‌ریزی شخصی.
- تاریخ شمسی محور است و میلادی کنار آن نمایش داده می‌شود؛ ساعت و تاریخ «امروز» از منطقه زمانی `Asia/Tehran`.
- مناسبت‌های مذهبی در رابط نمایش داده نمی‌شوند؛ مناسبت‌های غیرمذهبی حتی وقتی هم‌روز با رویداد مذهبی باشند حفظ می‌شوند.
- وضعیت فعلی داده رسمی: [مناسبت‌های بازبینی‌شده سال ۱۴۰۵](../data/years/1405.json)، بر اساس PDF دانشگاه تهران. داده معتبر دیگر سال‌ها هنوز وارد نشده و نباید نمونه‌های ۱۴۰۵ به آن‌ها تعمیم داده شوند.
- یادداشت‌ها در `localStorage` همان دستگاه ذخیره می‌شوند؛ دانلود و بازیابی پشتیبان JSON وجود دارد، اما همگام‌سازی خودکار نداریم.
- رابط ساده و موبایل‌محور است؛ فروهر نشان موقت است و هویت نهایی در آینده بررسی می‌شود.

## توسعه و امنیت
- سایت در GitHub Pages مخزن عمومی منتشر شده است؛ پایگاه داده اختصاصی یا سرور پولی نداریم.
- سیاست حقوق کد: [حقوق محفوظ](LICENSING.md)؛ فایل LICENSE در ریشه مخزن. حقوق PDF و داده ثالث جداست.
- مدیریت تجربه‌های مشترک اپ‌ها در [مخزن مادر](https://github.com/mckaren8089-stack/app-engineering-hub) انجام می‌شود.

- کارهای بعدی: دوام یادداشت‌ها و بازیابی، وضعیت واضح سال فاقد داده، آزمون UI/آفلاین و استانداردسازی نسخه؛ سپس امکانات ساده دفتر روزانه.
