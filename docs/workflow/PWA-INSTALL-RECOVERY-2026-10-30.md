# ثبت وضعیت — بازیابی نصب PWA روزنمای کارن

تاریخ ثبت: ۲۰۲۶-۱۰-۳۰
مالک: گفتگوی تخصصی عیب‌یابی نصب PWA
وضعیت: گزارش موفقیت عملی روی Android 15 و 16؛ علت ریشه‌ای تأییدنشده
Issue: https://github.com/mckaren8089-stack/karen-rooznama/issues/2
PR تشخیصی روزنما: https://github.com/mckaren8089-stack/karen-rooznama/pull/3

## شواهد و توالی
- گزارش جدید کاربر: Android 15 پس از refresh سایت، پنجره نصب به طور خودکار نمایان شد و نصب واقعی موفق بود.
- گزارش جدید کاربر: Android 16 پس از آغاز دستی نصب، پنجره مجوز آمد و پس از چند ثانیه نصب موفق شد.
- Android 14 پیش‌تر نصب موفق داشت. Desktop install test هنوز انجام نشده است.
- در هیچ‌یک از این دو موفقیت، اصلاح cache کارن‌فیوز از سوی این گفتگو در main منتشر نشده است.
- بررسی مستقیم کد main کارن‌فیوز نشان می‌دهد `sw.js` هنوز `keys.filter(key=>key!==CACHE)` را اجرا می‌کند؛ اصلاح namespace-scoped صرفاً در draft PR https://github.com/mckaren8089-stack/karen-fuse/pull/7 است و CI آن سبز شده است.
- بررسی مستقیم کد main روزنما نشان می‌دهد نسخه manifest و SW و کد نصب، همان نسخه‌های پیشین است. آخرین commit main روزنما `f84d3eb9924101cddc6e3b4d25617a8b115729d3` فقط فایل starter را افزوده است.
- آخرین commitهای main کارن‌فیوز در زمان بررسی، به‌روزرسانی خودکار داده بازار بودند؛ نه رفع اشکال نصب.
- آزمون زنده قبلی HTTP/MIME/PNG روزنما موفق بوده است: https://github.com/mckaren8089-stack/karen-rooznama/actions/runs/40863748297 .
- گزارش‌های خطای اطلاع‌رسانی GitHub در Gmail موجود هستند، ولی موارد بازبینی‌شده مربوط به اجراهای قدیمی در تاریخ ۲۸ اکتبر هستند و دلیلی بر خطای فعلی نصب نیستند.

## ارزیابی علت
- علت نصب ناموفق قبلی: هنوز معلوم نیست.
- نسبت دادن موفقیت فعلی به PR کارن‌فیوز: رد می‌شود چون PR هنوز ادغام نشده است.
- نتیجه‌گیری قطعی درباره تداخل same-origin یا شکست GitHub Pages: موجه نیست؛ نصب واقعی موفق روی origin فعلی رخ داده است.
- ایراد کد حذف cacheهای سایر برنامه‌ها در SW کارن‌فیوز همچنان واقعی است و به عنوان اصلاح مستقل در انتظار تصمیم است؛ حتی پس از انتشار هم اثبات نمی‌کند عامل نصب بوده است.

## تصمیم‌ها و اقدامات
1. فعلاً هیچ تغییر در شناسه PWA، start_url، scope، مسیر سایت، localStorage، داده کاربران یا حذف WebAPK اعمال نشود.
2. PR #7 کارن‌فیوز را صرفاً برای جلوگیری از حذف cache بین برنامه‌ها باز نگه داریم؛ ادغام فقط با تصمیم کنترل پروژه، و بعد از آن نتیجه را جداگانه اعتبارسنجی کنیم.
3. Issue شماره ۲ تا تأیید پایداری نصب و اجرای مستقل روی دستگاه‌ها باز بماند؛ وضعیت آن از «نصب ناموفق» به «نصب موفق گزارش شده، علت قبلی نامشخص / نیاز به پایش» تغییر یابد.
4. گزینه ساخت سازمان مستقل رایگان GitHub و origin مجزا حفظ شود؛ **فعلاً اجرا نشود**. در طراحی انتشار چند PWA در آینده دوباره بررسی گردد.
5. اگر مشکل دوباره ظاهر شد، زمان، نسخه Chrome/Android، نام PWA، و مرحله شکست WebAPK ثبت شود، بدون Clear site data.
