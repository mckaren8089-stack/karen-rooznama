# حقوق نشر و مجوز روزنمای کارن

**وضعیت فعلی:** حقوق کد اصلی محفوظ است؛ مجوز متن‌باز MIT، GPL، Apache یا مجوز بازاستفاده عمومی صادر نشده است.

- فایل [LICENSE](../LICENSE) اطلاعیه انحصاری «All rights reserved» برای حقوق موجود بر کد و محتوای اختصاصی پروژه است.
- مخزن GitHub **عمومی** است؛ عمومی بودن مخزن به معنی محرمانه بودن سورس نیست. نمایش کد و Fork در GitHub تابع شرایط خود GitHub است؛ این اطلاعیه حق بازاستفاده عمومی جداگانه نمی‌دهد.
- بازدید و استفاده معمول از وب‌اپ منتشرشده مجاز است، اما کپی و انتشار مجدد کد نیاز به حق یا اجازه مناسب دارد.
- هیچ ادعایی درباره مالکیت انحصاری روی کتابخانه‌ها، آثار ثالث، کد نمونه واردشده از ابزارها یا داده رسمی دانشگاه تهران نداریم. حقوق و شرایط بازنشر آن‌ها جداگانه باید بررسی شود.
- تغییر وضعیت مخزن به Private انجام نشده است؛ زیرا روی GitHub Free می‌تواند انتشار GitHub Pages را قطع کند.
- در آینده می‌توانیم کدی را که حقوقش را داریم تحت MIT منتشر کنیم؛ ولی تغییر آتی نباید به‌عنوان لغو مجوزهای احتمالی گذشته یا حقوق دیگران معرفی شود.
- Karen Fuse و App Engineering Hub نیز اطلاعیه حقوق محفوظ مستقل در فایل LICENSE مخزن خود دارند.

**تصمیم کد: بسته شده — حقوق انحصاری. بررسی حقوق داده دانشگاه تهران: باز.**
