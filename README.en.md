# Karen Rooznama

**Launch the app:** https://mckaren8089-stack.github.io/karen-rooznama/

**Language / زبان:** [فارسی](README.fa.md) | [English](README.en.md)

Karen Rooznama is a minimalist Iranian calendar and personal daily planner.

## Available features
- Monthly and yearly Persian calendar with Gregorian dates and Iran time
- Persian–Gregorian date conversion
- Nonreligious occasions curated from the official 1405 Iranian calendar
- Daily notes, editing, and deletion
- Manual JSON backup and restore for notes
- Installable progressive web app (PWA) on supported devices

## Planned improvements
- More reliable note storage and recovery
- Gradual support for future years' verified official calendar data
- Daily tasks and note search without cluttering the interface

**Privacy:** Notes stay in local browser/device storage; there is no automatic synchronization.
