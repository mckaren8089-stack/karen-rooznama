# روزنمای کارن | Karen Rooznama

**پایه توسعه ۰.۳ — پیش‌نمایش موبایلی** تقویم هجری شمسی و میلادی.

## نمایش آنلاین

بعد از فعال‌سازی GitHub Pages و موفقیت انتشار:
https://mckaren8089-stack.github.io/karen-rooznama/

## امکانات این Snapshot
- تقویم ماهانه و سالانه شمسی، با نمایش روز میلادی.
- انتخاب روز، رفتن به امروز، تبدیل تاریخ شمسی به میلادی و ساعت ایران.
- مناسبت‌های **سال‌محور** با فایل داده `data/years/1405.json` و نشانی مرجع رسمی دانشگاه تهران؛ پوشش فعلی **بخشی و در حال بررسی** است و هنوز کل تقویم رسمی وارد نشده. هیچ داده نمونه‌ای به سال‌های دیگر تعمیم داده نمی‌شود.
- یادداشت روزانه روی **همان دستگاه** با localStorage، نشان تعداد یادداشت‌ها، فهرست همه یادداشت‌ها، ویرایش و حذف با تأیید.
- **دریافت و بازیابی فایل JSON** برای پشتیبان‌گیری دستی؛ بدون ارسال یادداشت‌ها به سرور و بدون همگام‌سازی خودکار.
- manifest و Service Worker برای نصب اولیه PWA؛ نصب واقعی روی گوشی هنوز آزمایش نشده است.

## چهار پایه اصلی
- موتور تاریخ و آزمون‌ها
- داده سالانه از مرجع رسمی + پالایش مذهبی و کنترل منشأ
- یادداشت‌های تاریخ‌دار با مدیریت و پشتیبان JSON
- ساختار رابط موبایل‌محور و هویت اختصاصی روزنمای کارن

[وضعیت صریح پیشرفت و تصمیم‌های باز](docs/FOUR-FOUNDATIONS.md)

## کارهای برنامه‌ریزی‌شده
- ورود سالانه داده تقویم رسمی مرکز تقویم مؤسسه ژئوفیزیک دانشگاه تهران و فیلتر مناسبت‌های مذهبی در مرحله ورود داده.
- آزمون مرورگر اندروید و کنترل تطبیق تاریخ.
- ارزیابی انتقال بسته React/TypeScript اولیه به معماری نهایی.
