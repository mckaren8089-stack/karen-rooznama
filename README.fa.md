# روزنمای کارن

**اجرای آنلاین برنامه:** https://mckaren8089-stack.github.io/karen-rooznama/

**زبان / Language:** [فارسی](README.fa.md) | [English](README.en.md)

روزنمای کارن یک تقویم ایرانی مینیمال و دفتر سادهٔ برنامه‌ریزی شخصی است.

## امکانات فعلی
- تقویم شمسی ماهانه و سالانه همراه تاریخ میلادی و ساعت ایران
- تبدیل تاریخ شمسی و میلادی
- مناسبت‌های غیرمذهبی پالایش‌شده از تقویم رسمی سال ۱۴۰۵
- یادداشت روزانه، ویرایش و حذف یادداشت
- پشتیبان‌گیری و بازیابی دستی یادداشت‌ها با فایل JSON
- نصب به‌صورت وب‌اپ (PWA) روی دستگاه‌های سازگار

## در برنامه
- بهبود امنیت و پایداری ذخیره و بازیابی یادداشت‌ها
- تکمیل تدریجی دادهٔ رسمی سال‌های آینده
- برنامه‌ریزی کارهای روزانه و جست‌وجوی یادداشت‌ها، با حفظ سادگی ظاهر

**حریم خصوصی:** یادداشت‌ها در حافظهٔ همان مرورگر/دستگاه نگهداری می‌شوند؛ همگام‌سازی خودکار ندارند.
